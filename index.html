Скачать VPN-клиент

Выберите своё устройство. После установки импортируйте файл конфигурации, который прислал бот.

Основной вариант

Windows

Для основного файла .conf используйте AmneziaWG for Windows.

Скачать AmneziaWG для Windows 10/11 x64 Запасной вариант: WireGuard
Если .conf не виден при импорте — выберите “Все файлы”. Для WireGuard/WireSock берите файл с окончанием -wireguard.conf.
Основной вариант

Android

Для основного файла .conf используйте AmneziaWG. Можно поставить APK напрямую.

Скачать AmneziaWG APK AmneziaVPN в Google Play
Если телефон предупреждает про APK — разрешите установку из браузера. Если используете WireGuard — импортируйте -wireguard.conf.
iPhone / iPad

iPhone

Для iOS используйте AmneziaWG из App Store и импортируйте основной .conf или QR.

Открыть AmneziaWG в App Store Запасной вариант: WireGuard iOS
Если приложение недоступно в вашем регионе App Store — используйте WireGuard и файл -wireguard.conf.
MacBook / macOS

MacBook

На macOS самый простой запасной путь — WireGuard + файл -wireguard.conf. Для Amnezia используйте официальный клиент.

Скачать AmneziaVPN для macOS Запасной вариант: WireGuard macOS
Если AmneziaVPN просит ключ vpn://, используйте WireGuard и файл -wireguard.conf, который прислал бот.

Как подключить

  1. Скачайте приложение для своего устройства.
  2. Откройте приложение и нажмите + / Import from file.
  3. Выберите файл конфигурации из Telegram.
  4. Включите VPN.
Основной файл — для AmneziaWG. Файл с окончанием -wireguard.conf — для WireGuard/WireSock.

Если что-то не получилось — напишите в поддержку в Telegram-боте.
