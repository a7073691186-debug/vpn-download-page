Скачать VPN-приложение

Установите официальное приложение WireGuard/WireSock и импортируйте файл vpn.conf, который прислал бот.

Рекомендуем

Windows

Для Windows используйте WireSock. Он хорошо импортирует обычный файл vpn.conf.

Скачать WireSock с официального сайта Запасной вариант: официальный WireGuard
Если файл не виден — сохраните vpn.conf на рабочий стол и в окне выбора включите Все файлы (*.*).
Официальный источник

Android

Установите WireGuard и импортируйте файл vpn.conf или QR.

Скачать WireGuard в Google Play
На телефоне проще всего открыть QR из сообщения бота.
Официальный источник

iPhone / iPad

Установите WireGuard из App Store и добавьте туннель через QR или файл.

Скачать WireGuard в App Store
Если файл не открывается напрямую — используйте импорт по QR.
Официальный источник

MacBook / macOS

Установите WireGuard и импортируйте файл vpn.conf.

Скачать WireGuard в App Store
Если файл из Telegram получил расширение .txt — переименуйте обратно в vpn.conf.

Как подключить

  1. Скачайте приложение для своего устройства.
  2. Скачайте файл vpn.conf из Telegram-бота.
  3. Откройте приложение и нажмите + / Import from file.
  4. Выберите vpn.conf и включите VPN.
