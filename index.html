VPN-клиент для Windows

Скачайте AmneziaWG, установите приложение и импортируйте файл конфигурации .conf, который прислал бот.

Скачать для Windows 10/11 x64 Запасной вариант: WireGuard
Если Windows спрашивает разрешение — нажмите “Выполнить”. Если .conf не виден при импорте — выберите “Все файлы”.
  1. Установите AmneziaWG.
  2. Откройте приложение.
  3. Нажмите Import tunnel(s) from file.
  4. Выберите файл .conf из Telegram.
  5. Включите подключение.

Для Android/macOS используйте ссылку из бота на официальный сайт Amnezia. Для WireGuard используйте файл с окончанием -wireguard.conf.
