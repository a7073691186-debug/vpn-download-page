Скачать VPN

Простой способ: установите приложение WireGuard/WireSock и импортируйте файл vpn.conf, который прислал бот.

Основной вариант

Windows

Рекомендуем WireSock. Он импортирует обычный файл vpn.conf.

Скачать WireSock для Windows Запасной вариант: WireGuard
Если файл не виден — сохраните vpn.conf на рабочий стол и в окне выбора включите Все файлы (*.*).
Основной вариант

Android

Установите WireGuard и импортируйте файл vpn.conf или QR.

Скачать WireGuard в Google Play APK WireGuard
На телефоне проще всего открыть QR из сообщения бота.
Основной вариант

iPhone / iPad

Установите WireGuard из App Store и добавьте туннель через QR или файл.

Скачать WireGuard для iOS
Если файл не открывается напрямую — используйте импорт по QR.
Основной вариант

MacBook / macOS

Установите WireGuard и импортируйте файл vpn.conf.

Скачать WireGuard для macOS
Если файл из Telegram получил расширение .txt — переименуйте обратно в vpn.conf.

Как подключить

  1. Скачайте приложение для своего устройства.
  2. Скачайте файл vpn.conf из Telegram.
  3. Откройте приложение и нажмите + / Import from file.
  4. Выберите vpn.conf и включите VPN.
Если обычный способ не работает

Резервный режим AmneziaWG

AmneziaWG лучше проходит блокировки, но сложнее в установке. Используйте его только если WireGuard/WireSock не подключается.

AmneziaWG для Windows AmneziaWG для iPhone/iPad
Для AmneziaWG нужен отдельный резервный файл vpn-amneziawg.conf. В обычном сценарии используйте vpn.conf.

Если что-то не получилось — напишите в поддержку в Telegram-боте.
