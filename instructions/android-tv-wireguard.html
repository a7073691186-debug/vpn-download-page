WireGuard на Android TV

Главное: используйте файл vpn.conf, который прислал бот. Один файл — одно устройство. Доступ в тарифе — до 2 устройств.

Что понадобится

  • WireGuard из Google Play на телевизоре
  • Downloader by AFTV News
  • File Manager Plus
  • ссылка на скачивание vpn.conf из бота

Настройка

1. В боте создайте подключение для телевизора и нажмите «Ссылка для скачивания конфига».
2. На Android TV установите WireGuard, Downloader и File Manager Plus.
3. Откройте Downloader и вставьте ссылку на скачивание конфига.
4. Скачайте файл vpn.conf.
5. Откройте WireGuard, нажмите «+» и выберите импорт из файла.
6. Через File Manager Plus откройте папку загрузок/Downloader и выберите vpn.conf.
7. Включите подключение. Если счётчики передачи растут — VPN работает.

Если не подключается

Перезагрузите телевизор долгим нажатием кнопки питания и попробуйте снова.

Не получилось?
Скачайте файл заново в боте или напишите в поддержку. Открыть бота
