WireGuard/WireSock на Windows 7/8/10/11

Главное: используйте файл vpn.conf, который прислал бот. Один файл — одно устройство. Доступ в тарифе — до 2 устройств.
Скачать WireSock для Windows

Настройка

1. В Telegram-боте нажмите «Создать подключение» и получите файл vpn.conf.
2. Сохраните vpn.conf на рабочий стол или в «Загрузки».
3. Установите WireSock и откройте приложение.
4. Нажмите «+» / Add profile и выберите файл vpn.conf.
5. Включите подключение переключателем.
6. Если цифры Received/Sent растут — VPN работает.

Если файл не виден

В окне выбора файла включите «Все файлы (*.*)» или перенесите vpn.conf на рабочий стол.

Если нет интернета

Отключите VPN, включите снова. Если не помогло — перезагрузите компьютер и проверьте, не блокирует ли WireSock антивирус.
